# Sample listing photos

Demo/seed data only. These photos were downloaded from [Unsplash](https://unsplash.com)
and are used under the [Unsplash License](https://unsplash.com/license) (free to use,
attribution appreciated but not required). File names are the Unsplash CDN photo IDs
(`https://images.unsplash.com/photo-<id>`), so each one can be traced back to its
source page and photographer.

They are used only by `npm run seed` (see `src/seed/seed.ts`). Replace them with
your own photography before any real launch.

`apps/web/public/hero.jpg` and `apps/web/public/auth.jpg` (landing hero and sign-in
panel) come from the same source (`1564013799919-ab600027ffc6` and
`1613490493576-7fde63acd811`).
